## Observações

- Os identificadores numéricos dos arquivos (`photo-1577746838851-...`) são os IDs da CDN
  do Unsplash. O nome de cada autor pode ser confirmado abrindo a respectiva URL direta
  no navegador (a página da CDN redireciona / o ID é pesquisável no unsplash.com).
- As zonas "Antes / Depois" da seção Resultados **permanecem ilustrativas** (arte SVG
  rotulada como "Imagem ilustrativa"), pois não há fotografia adequada de paciente real —
  conforme guardrail de comunicação responsável da marca.
- Overlay/duotone quente aplicado por CSS (sem alterar os arquivos) para harmonizar as
  fotos com a paleta Champagne/Petróleo/Dourado da Lúmina.
